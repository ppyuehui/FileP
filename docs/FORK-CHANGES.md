# FileP 与原版 Pulse 的差异清单

> 本文件用来核对「我们改了什么」。基线：官方 `jimmgreen/pulse` v1.0.59（提交 `0856a655`）。
> 每次合并官方新版本后，请回来过一遍这张表，确认每一项仍然成立。

- 我们的仓库：`https://git.huihui.xx.kg:2222/hui/FileP.git`（另有 `local` / `github` 两个镜像）
- 分支：`main`；上游远程名 `upstream`（只 fetch）
- 产品名/进程名：`FileP.exe`（其余辅助进程仍是官方名字，见文末「已知遗留」）

## 二、新增功能（官方没有）

### 1. 自定义命令（最大的一块）

| 能力 | 说明 |
| --- | --- |
| 数据模型 | `commands.json`：名称 / 出现位置 / 步骤列表；设置备份与迁移一并包含 |
| 步骤类型 | 新建文件夹、新建文件、运行程序、批处理脚本 |
| 占位符 | `{name}` = 选中项名称；命令在「当前文件夹」里执行 |
| 设置页 | 侧栏「自定义命令」（第 16 页），主从双栏：左边命令列表 + 新建/删除，右边名称、出现位置、步骤区 |
| 行内编辑 | 名称与步骤值都是原生输入框（合成器绘制，和页面字体一致），Tab 在两个字段间切换 |
| 步骤操作 | 添加 / 更新 / 上移 / 下移 / 删除，行内悬停出现 ↑↓✕ |
| 摘要 | 「将执行：a → b → c」一句话预览 |
| 右键菜单 | 按每条命令的「出现位置」（工具栏 / 右键文件夹 / 右键空白处）显隐 |
| 工具栏 | 可钉到工具栏，id 为 `cmd:<序号>`，图标是命令图标 |
| 执行 | 在 I/O 后台线程跑，完成后 `WM_CUSTOM_COMMAND_DONE`（`WM_APP+200`）回到 UI 刷新；失败弹框 |
| 回归测试 | `pulse_custom_commands_test`（12 项，含序列化往返） |

### 2. 界面选项

| 设置项 | 位置 | 作用 |
| --- | --- | --- |
| 任务栏标题字符数（父目录 / 当前文件夹） | 外观 → 文字 | 1–12 档滑块，12 = 不限；只截断末尾并加省略号 |
| 地址栏主页按钮 | 外观 | 地址栏左侧多一个「此电脑」按钮（切换号 84） |
| 地址栏复制按钮 | 外观 | 地址栏右侧的复制按钮可关（切换号 82） |
| 自动收起侧栏 | 外观 | 窗口变窄时侧栏自动收成图标栏；手动点开则本窗口不再自动收（切换号 83） |
| 「最近变化」悬停详情可关闭 | 文件列表 | 悬停卡片右上角 ✕（切换号 85） |

### 3. 窗口与布局

- 左右分屏按钮变成**开关**：分屏中图标变蓝，再点一次退出。
- 标签页关闭按钮：**松开鼠标**才生效（按下可反悔）。

## 三、行为调整（官方原样 → 我们的做法）

| 场景 | 我们的做法 |
| --- | --- |
| 窄窗口左上角按钮 | 只当侧栏开关，不再弹出「改名/换颜色」菜单 |
| 收藏夹栏 | 图标化阈值 820 → 320 DIP（半屏时不再退化成纯图标） |
| 右键菜单二级菜单 | 加「安全三角」，斜向移动不会被旁边的项抢走 |
| 重命名 | 隐藏已知扩展名时，输入框里只编辑主名，提交后自动补回扩展名 |
| 变化记录 | 从「文件操作」页挪到「文件列表」页，和修改时间提示放一起 |
| 设置文件 | 搬到 `%APPDATA%\FileP`，旧的 `Pulse` 目录首次启动自动迁移 |

## 四、缺陷修复（官方版本里存在问题、我们已修）

| 问题 | 修复 |
| --- | --- |
| 局域网设备打开时带 `.local` 后缀，进不去 | `LanDeviceUnc` 去掉 mDNS 后缀 |
| 网络盘文件的标签每次启动都重试并弹「不支持文件标签数据」 | 永久性失败（无 `FILE_NAMED_STREAMS`）从重试队列剔除 |
| 任务栏标题的两个滑块拖不动 | `SliderValue` 增加 6/7 号处理 |
| 标题栏最小化/最大化/关闭单击无反应 | 去掉 `WS_SYSMENU`，按钮在 `WM_NCLBUTTONDOWN` 里按下即执行（官方 1.0.59 同样是按下即执行） |
| 「左右分屏」按钮点了没反应 | 改为开关并重算图标状态 |
| 收藏夹栏过早退化成纯图标 | 阈值 820 → 320 |
| 手动展开侧栏在窄窗口下无效 | 记录「用户强制展开」标记 |
| 复制路径按钮被收藏栏挡掉 | 命中顺序修正 |
| 代码审查（两轮）发现的问题 | AI 工具层、更新/安装、标签托盘胶水层若干缺陷 |

## 四点五、合并 1.0.59 后「官方自己也有了」→ 已删除

| 原来自研的 | 官方 1.0.59 的做法 | 处理 |
| --- | --- | --- |
| 设置「显示 AI 入口」开关（切换号 81） | 设置 → AI 助手 → **启用**，关掉后状态栏芯片自动消失 | **已删除**我们的开关（且它和官方「排列窗口 · 最小化也排列」的 81 号撞车了） |
| 标题栏三按钮「按下即执行」 | 官方同样在 `WM_NCLBUTTONDOWN` 里按下即执行 | 不再是差异，只是保留「无 `WS_SYSMENU`」这一条 |
| 侧栏分组条目缩进一级 | 官方竖向标签同样 `indent + (有标题 ? 1 : 0)` | 不再是差异 |

## 七、号段占用（合并官方新版时必查）

官方 1.0.59 恰好占用了我们早期用的号段，已整体迁移。**以后新增任何 id，先跟 upstream 对一遍。**

| 类型 | 我们的范围 | 说明 |
| --- | --- | --- |
| 字符串 ID | `6400–6445` | 官方 1.0.59 用到 6390，且把我们原来的 5670–5690 占了 |
| 设置页「自定义命令」 | `16` | 官方占了 13（AI 与 MCP）、14（AI 助手）、15（插件设置） |
| 自定义命令命令号 | `5700–5799` | 官方占了 5199/5200 |

| 工具栏槽位 id | `cmd:<序号>` | 与官方 `IsToolbarTool` 并存，用 `IsToolbarSlot` 判断 |
